v2.1 · 2026.08.13 · Master: 02_대화동행_MVP설계서_v2.1.md · 흐름: 03_대화동행_Flowchart_v2.1.html · UI 대안: 05_대화동행_UI_ABC안_v2.1.html
이 문서의 역할 — Flowchart(03)의 OCR-05, MED-05 같은 Screen ID를 보고 해당 화면의 모습 · 목적 · 표시 정보 · 버튼 · 다음 화면 · 필요한 데이터 · 오류/예외를 확인하는 문서입니다. 디자인 시안이 아닙니다. 화면 안의 약 이름·수치는 배치 확인용 임의 예시이며 사실이 아닙니다.
MVP 구현 단계 (Cut-line) — 39개 화면을 8~9월에 전부 완성해야 한다는 뜻이 아닙니다. 각 화면 제목 옆 배지를 보세요.
MVP: MUST 기능검증 MVP에서 반드시 구현   MVP: SIMPLIFY 구현은 필요하나 다른 화면에 합치거나 단순화 가능   MVP: LATER MVP 이후 또는 시간이 남을 경우
[MVP Cut-line 팀 확정 필요] — 아래 구분은 제안이며 팀이 확정하지 않았습니다. Decision Log S-3 참조.

적용한 고령자 UX 원칙 (화면 안 글자·버튼 크기는 실제 px 값)

  • 큰 글씨 — 본문 20px, 핵심 안내 22~27px, 버튼 라벨 22px
  • 큰 버튼 — 주요 버튼 높이 72px 이상, 가로폭 전체
  • 충분한 터치 영역 — 요소 간 간격 14px 이상
  • 선택지 과다 금지 — 화면당 주요 선택지 최대 2개
  • IT 용어 최소화 — "OCR"·"DUR"·"업로드"·"동기화" 화면 문구에 미사용
  • 핵심 기능 명확화 — 화면당 주 동작 1개를 가장 진하게
  • 쉬운 수정·복귀 — 전 화면 좌상단 [←], 확정 직전 [다시 찍기] 상시 노출
  • 주의 정보 인지 — 상단 배치 + 테두리 + 아이콘. 색상에만 의존하지 않음
  • 의사결정 압박 금지 — 동의/미동의, 참여/거절 선택지를 시각적으로 균등하게
