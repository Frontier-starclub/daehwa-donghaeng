도형 규칙

시작 / 종료 앱 화면 (Screen ID 표기) 조건 분기 AI / 서버 처리 외부 API (좌측 굵은 선) DB 저장 오류 · 예외 추가 결정 필요 / MVP 임시 제안 (확정 아님)
이 문서는 흐름을 보는 문서입니다. UI 모습·버튼 모양·화면 미리보기는 넣지 않습니다. 파란 Screen ID를 누르면 화면설계서의 해당 화면으로 이동합니다 (두 파일이 같은 폴더에 있을 때). 링크가 열리지 않는 환경이라면 동일한 Screen ID로 화면설계서에서 직접 찾으세요.
